معرفی

Intro

نیکا نت یک Cloudflare Worker است که هم‌زمان نقش پروکسی (VLESS و Trojan روی WebSocket) و پنل مدیریت را دارد. همه‌چیز در یک فایل worker.js جمع شده و روی پلن رایگان اجرا می‌شود.

Nika Net is a single Cloudflare Worker that acts as both a proxy (VLESS and Trojan over WebSocket) and a management panel. Everything is bundled into one worker.js and runs on the free plan.

Limits · free plan

۱۰۰٬۰۰۰ درخواست در روز، ۱۰ms CPU برای هر درخواست، بدون UDP. برای تماس صوتی/تصویری از خروجی WARP استفاده کن.

100,000 requests/day, 10 ms CPU per request, no UDP. Use the WARP export for voice/video.

استقرار

Deploy

روش ۱ — یک کلیک

Option 1 — One click

روی Deploy to Cloudflare بزن، وارد حساب Cloudflare شو و مراحل را تأیید کن. در پایان آدرسی مثل https://nika-net.<you>.workers.dev می‌گیری.

Click Deploy to Cloudflare, sign in and confirm. You'll get a URL like https://nika-net.<you>.workers.dev.

روش ۲ — خط فرمان

Option 2 — CLI

git clone https://github.com/NikaTeem/Nika-Net.git
cd Nika-Net
npm install
npm run build          # → dist/worker.js
npx wrangler login
npm run deploy

روش ۳ — دستی در داشبورد

Option 3 — Dashboard paste

  1. Cloudflare → Workers & Pages → Create Worker
  2. Cloudflare → Workers & Pages → Create Worker
  3. محتوای dist/worker.js را جای‌گذاری کن → Save and Deploy
  4. Paste dist/worker.js → Save and Deploy
  5. /admin را باز کن و رمز را در اولین ورود تعیین کن
  6. Open /admin and set the password on first login

ذخیره‌سازی

Storage

بدون binding، داده در حافظه است و با هر دیپلوی پاک می‌شود. برای پایداری یکی از این دو را متصل کن:

Without a binding, data lives in memory and resets on redeploy. Bind one of these for persistence:

BindingنوعTypeتوضیحNotes
NIKA_KVKV namespaceساده‌ترین؛ Workers → Settings → Bindings → KVSimplest; Workers → Settings → Bindings → KV
NIKA_DBD1 databaseجدول kv (key TEXT PRIMARY KEY, value TEXT) را بسازCreate table kv (key TEXT PRIMARY KEY, value TEXT)

پنل ادمین

Admin panel

مسیر پیش‌فرض /admin است؛ از تنظیمات می‌توانی آن را به یک مسیر مخفی تغییر دهی. زبان (FA/EN) و تم (روشن/تیره) با دکمه‌های بالای پنل عوض می‌شوند. هر مسیر ناشناس یک صفحه‌ی استتار بی‌ضرر نشان می‌دهد.

Default path is /admin; change it to a hidden path in Settings. Language (FA/EN) and theme toggle from the top bar. Unknown routes serve a harmless decoy page.

کاربران

Users

  • سهمیه (GB) و مدت (روز) برای هر کاربر؛ صفر یعنی نامحدود
  • Quota (GB) and days per user; zero means unlimited
  • هر کاربر یک لینک اشتراک خصوصی دارد: /sub/<token>
  • Each user has a private subscription link: /sub/<token>
  • غیرفعال کردن فوری با یک کلیک؛ حذف کاربر UUID را باطل می‌کند
  • Instant toggle off; deleting a user revokes the UUID

اسکنر IP تمیز

Clean-IP scanner

از مرورگر خودت ۴۲۰+ آی‌پی Cloudflare را روی پورت‌های TLS تست می‌کند و بر اساس تأخیر مرتب می‌کند. «Apply» بهترین‌ها را در تنظیمات ذخیره می‌کند و همه‌ی کانفیگ‌ها از آن‌ها استفاده می‌کنند. بخش Relay Test هم بهترین دامنه‌ی رله (workers.dev یا دامنه‌ی خودت) را پیدا می‌کند.

Probes 420+ Cloudflare IPs on TLS ports from your browser and ranks them by latency. "Apply" saves the best to settings and every config uses them. Relay Test finds the healthiest relay domain (workers.dev or your own).

امنیت

Security

  • رمز ادمین با SHA-256 هش می‌شود؛ نشست‌ها با HMAC امضا و به کوکی HttpOnly محدودند
  • Admin password is SHA-256 hashed; sessions are HMAC-signed HttpOnly cookies
  • مسیر ادمین را تغییر بده و لینک اشتراک را فقط به خود کاربر بده
  • Change the admin path and share subscription links only with their owner
  • Trojan برای شرایطی که VLESS شناسایی می‌شود پنهان‌کارتر است
  • Trojan is stealthier when VLESS gets fingerprinted

رفع اشکال

Troubleshooting

کانفیگ وصل نمی‌شود

Config won't connect

  • اسکنر IP را اجرا و Apply کن؛ سپس اشتراک را در کلاینت به‌روزرسانی کن
  • Run the IP scanner and Apply; then refresh the subscription in your client
  • Relay Test را اجرا کن — گاهی workers.dev در یک ISP بسته است
  • Run Relay Test — workers.dev is sometimes blocked on a given ISP
  • پروتکل را به Trojan تغییر بده
  • Switch the protocol to Trojan

بعد از دیپلوی کاربران پاک شدند

Users vanished after redeploy

Binding ذخیره‌سازی نداری. بخش ذخیره‌سازی را ببین.

You have no storage binding. See Storage.

خطای 1101 / CPU

Error 1101 / CPU limit

تعداد کاربران هم‌زمان زیاد است یا اسکن IP از خود Worker اجرا شده؛ اسکنر همیشه از مرورگر اجرا می‌شود.

Too many concurrent users, or the IP scan ran from the Worker; the scanner always runs from the browser.
