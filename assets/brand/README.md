Rules
1. Never stretch, recolor or add effects to the portrait. Grayscale is fine; inversion is not.
2. Keep at least the height of the "N" as clear space around the logo.
3. Paper (#d8d1c2) + Ink (#171512) are the brand; Seal red (#a8322a) is an accent — use sparingly.
4. Name is written "Nika Net" (two words) in Latin, «نیکا نت» in Persian.
5. Tagline: Connecting Intelligence. Slogan: «اینترنت، دست‌نوشتهٔ خودت.»
